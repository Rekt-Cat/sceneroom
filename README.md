# SceneRoom

A browser-based, real-time collaborative 3D scene editor, like Figma but for 3D environments.
Several people open the same scene and edit it together, live.

> **Status: in development.** Nothing is deployed yet. This README grows as features are built.

## Planned stack

TypeScript, Next.js (React), Three.js via React Three Fiber, Yjs for real-time sync,
Node.js WebSocket server, PostgreSQL, Docker, GitHub Actions.

## Project goals

- Learn and demonstrate a modern full-stack web stack end to end.
- Document decisions and trade-offs as the project grows (see `docs/` once it exists).
